# Independent LZX test specimens

The two `.lzx` files are byte-for-byte extractions of the compressed fixture
arrays in libfwnt's `tests/fwnt_test_lzx.c`, pinned to commit
`1178a070894abfbf0860b6b52842c89993ca0223`, source blob
`ae5dce65cf4e3d16fc11b459b131048afab7fd4d`:

https://github.com/libyal/libfwnt/blob/1178a070894abfbf0860b6b52842c89993ca0223/tests/fwnt_test_lzx.c

These files are inert decoder test inputs. Their decompressed data are libyal
libcerror DLL specimens; FrankenFS does not load or execute them. Neither the
specimens nor their expected output are generated by FrankenFS's decoder.

| File | Upstream compressed array | Stored bytes | Expected array | Output bytes |
| --- | --- | ---: | --- | ---: |
| libfwnt_verbatim.lzx | fwnt_test_lzx_compressed_data1 | 7520 | fwnt_test_lzx_uncompressed_data1 | 28672 |
| libfwnt_aligned.lzx | fwnt_test_lzx_compressed_data2 | 8054 | fwnt_test_lzx_uncompressed_data2 | 10752 |

The first uses a verbatim LZX block and the second an aligned block. Both
exercise native recent-offset reuse, pretree length runs and E8 translation.
The executable Rust regression checks SHA-256 of both input and full output
using the existing sha2 dependency. Expected output digests were calculated
from the independent upstream uncompressed arrays, not decoded candidates.
